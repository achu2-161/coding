# coding

Adrian's coding hub: a shared knowledge base and project tracker for learning Python and building data tools for PhD research on embodied GHG emissions in residential retrofit.

## What's here

| File | What it holds |
|---|---|
| [`CLAUDE.md`](CLAUDE.md) | Instructions every Claude chat follows when working with this repo |
| [`knowledge-base/profile.md`](knowledge-base/profile.md) | Who I am and what my research is about |
| [`knowledge-base/goals.md`](knowledge-base/goals.md) | What I want to be able to do, and by when |
| [`knowledge-base/skills.md`](knowledge-base/skills.md) | What I already know, what's shaky, and what I haven't started |
| [`knowledge-base/curriculum.md`](knowledge-base/curriculum.md) | The five-phase Python plan and where I'm up to |
| [`knowledge-base/projects.md`](knowledge-base/projects.md) | Things I've built or am building |
| [`knowledge-base/conventions.md`](knowledge-base/conventions.md) | Terminology, style, and how I like to work |
| [`knowledge-base/chats.md`](knowledge-base/chats.md) | Which Claude chat does what |
| [`knowledge-base/progress-log.md`](knowledge-base/progress-log.md) | Dated log of sessions and milestones |

## How to use it
- **Starting a new Claude chat:** point it at this repo and say which role it has (see `chats.md`).
- **After a session:** ask the chat to update the progress log and skills.
- **Code and exercises:** will go in folders by phase (`phase-1-foundations/` and so on) as they're written.
